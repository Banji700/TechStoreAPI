## Summary

This is the backend for my ecommerce store web API, Techtronica. This project has functionality for product managment, 
shopping carts, authentication, payments, product filtering ,orders and discount codes.
Within this project users are able to search for products, add and manage thier items in their cart,
register and login using JWT authentication, apply discount codes and process payments using Stripe.

## Stack
For this API I used: 

-ASP.NET Core Web API

-Angular

-SQL Server & Azure SQL 

-Stripe

-Azure App Service
